# ADR-0121：追更播放按浏览器能力选编解码梯子，分片按不可变资源交给浏览器缓存

- 状态：已采纳
- 日期：2026-10-25
- 相关：ADR-0120（起播钉最高档）、ADR-0119（母清单带全部档位、解析结果落盘复用）、ADR-0114（清单改写播放）、ADR-0016（远端媒体读取口径）

## 背景

ADR-0120 之后起播就钉最高档，慢网时表现为等缓冲。用户反馈「原站点起播和拖动都比这里快，
原站点同样放 4K」，要求查清差异。

实测（本机 headed Chrome、硬解、同一条 xHamster 条目、同一张 CDN）：

- 作品页 `<link rel="preload" as="fetch">` 指向的是 `_TPL_.av1.mp4.m3u8`：站点自己的播放器
  走 AV1 那条梯子，Peach 一直按 h264 那条解析。
- 同为 3840×2160、282 段、每段 4 秒：h264 平均 13.3 Mbps（峰值 19.96），中位分片 4.63 MB；
  AV1 平均 3.85–5.78 Mbps，中位分片 1.02 MB。
- 裸 hls.js 直连 CDN 的 4K：起播 1897 ms（h264）/ 1517 ms（av1）；冷拖到 60% 3436 ms、
  13.8 MB（h264）对比 604 ms（av1）；经 Peach 代理时冷拖 3.4 s、14.5 MB。
- 上游对分片回 `cache-control: public, max-age=315360000`，Peach 改写后一律回 `no-store`，
  于是回拖相同位置永远回源。
- 77 号条目的解析结果从来没有落盘：xHamster 把到期时刻写在路径里（`…==,1792926000/media=hls4/…`），
  只认 `validto=`／`end=` 的判据认不出，每次打开都重抓作品页，`/follow-stream` 首字节多等 1.8 s。

## 决策

1. **两条梯子都留着，按浏览器报得出的能力挑。** 前端用
   `MediaSource.isTypeSupported('video/mp4; codecs="av01.0.05M.08"')` 判断，能解就在片源地址上带
   `codec=av1`，服务端把它翻译成「先换 AV1 那一档、换不成再用 h264」；报不出来就沿用 h264。
   两条梯子各自落盘一份解析结果，互不顶掉。
2. **h264 永远是兜底档。** 换签被 CDN 拒（`403 Wrong key`）时落到页面自己那一档，播放不受影响；
   认不出的 `codec=` 当作没点名。
3. **分片对浏览器可缓存。** 短键是上游地址的摘要，同一把键永远是同一段字节，`/follow-hls`
   的非清单响应回 `private, max-age=3600, immutable`；带 `content-range` 的部分响应、清单本身、
   错误响应仍回 `no-store`。
4. **到期时刻的两种写法都认。** 除 `validto=`／`end=` 之外，路径里的 `,<epoch>/` 也算，判据取
   全部地址里最早的那个戳。

## 后果

- 4K 起播和拖动都按三分之一的字节走，慢网收益最大；像素与档位选择不变，仍是最高一档。
- 观众回拖已看过的位置命中浏览器缓存，不再经上游、也不再有 370 ms 的首字节等待。
- 不支持 AV1 的浏览器（如部分 Safari、旧显卡驱动）行为与之前完全一致。
- Peach 自己仍不把分片写进磁盘缓存：缓存交给浏览器，磁盘占用不变。
- 回归：`tests/test_follow_xhamster.py` 与 `tests/test_follow_stream.py` 覆盖两种到期写法、
  两条梯子的解析与落盘、换签失败回落；`tests/test_fastapi_api.py` 覆盖 `codec=` 透传与
  分片的 `cache-control`；`frontend/test/player.test.ts` 覆盖 `codecQuery()` 与「追更片源出错
  不换成 `/stream`」。

## 拒绝方案

- **改回 h264 一条梯子**：字节仍是四倍，起播与拖动照旧慢，且与站点自己的选择相反。
- **只按 User-Agent 猜 AV1**：Chrome 家族在软解机器上也会拒 av1，播放器报的能力才是准的。
- **没有 AV1 就整条拒绝播放**：把可用性押在编码上，Safari 会失去这一来源。
- **把分片也写进 Peach 的磁盘缓存**：与浏览器缓存重复，且要额外管 7 天保留与清扫；
  这里的复用目标是「回拖不出网」，浏览器自己那份已经够。
